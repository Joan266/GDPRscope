## Flujo de usuario (progressive trust)

```
NIVEL 0 — Anonimo (dia 1)
  → Usa simulador, busqueda, DPA profiles sin registro
  → Valor inmediato, cero barrera

NIVEL 1 — Registro ligero (email)
  → Research memory: "recuerda tus busquedas"
  → "Desde tu ultima visita, 2 nuevas decisiones relevantes"

NIVEL 2 — Auto-profile (pega URL)
  → Scraper extrae privacy policy
  → LLM parsea perfil organizacional
  → Todo se personaliza automaticamente

NIVEL 3 — Refinamiento manual (opcional)
  → El usuario corrige/amplía el perfil auto-detectado
  → Maximo valor, maximo engagement
```

## Pages / Tabs

### 1. Enforcement Analyzer (pagina principal)

Hero section con dos opciones de entrada:

**Opcion A: Quick Analysis (sin perfil)**
- Formulario manual: jurisdiccion, sector, articulos, factores
- Funciona exactamente como el simulador actual

**Opcion B: Smart Analysis (con URL)**
- Input: "Paste your company URL"
- Boton "Analyze"
- Loading: "Scanning privacy policy..."
- Resultado: perfil auto-detectado con confirmacion
- Luego: simulador pre-rellenado con datos del perfil

**Output del Analyzer:**

Range visualization bar (Zillow-style):
```
|---[====P25====|==MEDIAN==|====P75====]---|
MIN                                        MAX
          "Most likely range"
```
- Banda oscura = P25-P75 ("where 50% of similar fines fell")
- Fade gradual hacia P10/P90
- Color coding: green (low) → amber (medium) → red (high)

Confidence badge:
- High (20+ precedents, narrow IQR): "High confidence — 47 similar cases"
- Medium (10-19): "Moderate confidence"
- Low (<10): "Limited data — directional only"

Factor impact cards (con data backing):
```
[x] Cooperated with DPA        -15%  (based on 243 cases)
[ ] Intentional violation       +30%  (based on 71 cases)
[x] Took corrective measures    -10%  (based on 156 cases)
```

Precedent sidebar (top 5):
```
AEPD v. Company X (Spain, 2024)
Art. 5, 6 | Telecom | EUR 50,000 | Similarity: 87%
```

DPA comparison strip:
```
Spain: EUR 15K  |  France: EUR 120K  |  Ireland: EUR 300K
[=====]          [================]    [=====================]
```

### 2. My DPA (perfil de tu autoridad)

Si hay org_profile → muestra automaticamente la DPA del usuario.
Si no → selector de jurisdiccion.

Contenido del perfil DPA:
- Total decisiones en nuestra DB
- Multa mediana, media, maxima
- Top 5 articulos mas sancionados (con %)
- Top 3 sectores mas multados
- Tendencia temporal (creciendo/estable/decreciendo) con sparkline
- Cooperacion: cuanto reduce la multa en esta DPA
- Velocidad: tiempo medio investigacion → decision (si disponible)
- Comparacion: "La AEPD multa 3x menos que la CNIL por Art. 6"
- Decisiones recientes (ultimas 5)

### 3. Search (buscador mejorado)

- Si hay org_profile: filtros pre-rellenados con jurisdiccion/sector del usuario
- Barra de busqueda de texto libre
- Sidebar con filtros: jurisdiccion, articulo, sector, rango multa, ano
- Resultados como cards con relevancia al perfil (badge "Relevant to you" si match)
- Ordenar por: relevancia, multa, fecha

### 4. Memory (centro de memoria — el "wow" del demo)

**Panel izquierdo: Research Timeline**
- Lista cronologica de todas las consultas previas
- Cada entrada: query, filtros, fecha, resultados count
- Click → re-ejecutar la busqueda

**Panel derecho: Updates Since Last Visit**
- Nuevas decisiones que matchean tus consultas previas
- Nuevas decisiones que matchean tu perfil organizacional
- Badge: "3 new decisions affect your profile"
- Cada update con "Why this matters to you:" + explicacion contextual

**Panel inferior: Organization Profile**
- Si existe: muestra perfil auto-detectado con opcion de editar
- Si no: CTA "Add your company URL for personalized alerts"

### 5. Compare DPAs

- Multi-selector de DPAs (2-5)
- Tabla lado a lado con stats completos
- Graficos de barras comparativos
- "If your case were in [country], the median fine would be..."

### 6. Trends

- Graficos de lineas: multas/ano, casos/ano, mediana/ano
- Filtrable por: jurisdiccion, sector, articulo
- Heatmap: articulo x ano (intensidad = multa total)
- Si hay perfil: highlight de la jurisdiccion/sector del usuario

## Principios de diseno (implementados)

- **Data-first**: numeros y rangos son protagonistas — IMPLEMENTADO
- **Links a fuentes**: cada dato tiene link al documento original — IMPLEMENTADO (Case Detail)
- **Sin prosa generada**: todo es datos reales o calculos transparentes — IMPLEMENTADO
- **Progressive disclosure**: minimo necesario primero, detalles on-demand — IMPLEMENTADO (expanders)
- **Confidence always visible**: nunca mostrar un numero sin su confianza — IMPLEMENTADO (badge)
- **Memory as feature**: hacer visible que el agente recuerda — PENDIENTE (tab Memory)
- **Framing legal**: "exposure range", no "prediction". Disclaimer siempre visible — IMPLEMENTADO
- **Security**: XSS-safe (html.escape), SQL parametrizado, service layer — IMPLEMENTADO
- **Modular**: archivos < 200 lineas, componentes reutilizables — IMPLEMENTADO
