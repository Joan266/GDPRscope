### Paso 2: Escribir `db/embed.py`

Script que:
1. Lee chunks sin embedding (`WHERE embedding IS NULL`)
2. Llama a Bedrock Titan Text Embeddings V2 (`amazon.titan-embed-text-v2:0`, 1024 dims)
3. Actualiza el campo `embedding VECTOR(1024)` en la tabla `chunks`

Skeleton del cliente Bedrock:
```python
import boto3, json
bedrock = boto3.client("bedrock-runtime", region_name="us-east-1")

def embed(text: str) -> list[float]:
    body = json.dumps({"inputText": text, "dimensions": 1024, "normalize": True})
    r = bedrock.invoke_model(modelId="amazon.titan-embed-text-v2:0", body=body)
    return json.loads(r["body"].read())["embedding"]
```
